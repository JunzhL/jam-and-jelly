# 🎵 Jam & Jelly

The shared home for our band's music — sheet music, recordings, written parts, and
practice notes. Everything is version-controlled so nothing gets lost and we can always
see who changed what.

## What's in here

| Folder | What goes in it |
|--------|-----------------|
| `scores/` | Sheet music — PDFs and scans |
| `audio/` | Reference recordings and backing tracks |
| `parts/` | Written or arranged parts (per song / per instrument) |
| `practice-notes/` | Notes from rehearsals and ideas |
| `docs/` | Guides (start here 👇) |

## How to contribute — two easy ways

You do **not** need to know Git or coding. Pick whichever suits you:

1. **From Slack (easiest)** — chat with our band bot, or drop a file straight into the
   `#jam-and-jelly` channel. See **[docs/CHAT-GUIDE.md](docs/CHAT-GUIDE.md)**.
2. **From your laptop** — keep the files in a folder and let Claude handle the rest.
   See **[docs/BAND-GUIDE.md](docs/BAND-GUIDE.md)**.

## How changes are kept safe

- Nobody edits the shared "main" copy directly.
- Every change is proposed first, the band gets a notification in Slack, and it only
  becomes official once someone clicks **Approve**.
- Tasks ("find the horn chart", "record a scratch track") are tracked in Linear and
  show up in Slack.
